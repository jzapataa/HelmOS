# Propuesta separada — preparación de conectores sociales

Estado: propuesta documental pendiente de decisión; no modifica `SYSTEM_SPEC_V1.0.md`.

La petición explícita de I4-A1 autoriza preparar conectores, documentación y pruebas simuladas. La especificación vigente mantiene las integraciones API fuera de V1.0 (§§1 y 5) y denomina I4 al incremento de Personal (§4). Por ello el trabajo se identifica como **I4-A1 solicitado**, sin reasignar el I4 aprobado ni declarar ampliado o terminado V1.0.

Se propone registrar una línea adicional de evolución de Social para conectores oficiales, con aceptación independiente de Personal. Este primer incremento comprende viabilidad, contrato de proveedor autorizado, adaptadores de lectura y pruebas ficticias. La activación real requiere comprobar elegibilidad, permisos y contratos actuales de cada aplicación; no se presupone autorización de producción.

La misma pieza de vídeo en Instagram y TikTok conserva una referencia editorial explícita compartida y observaciones independientes por plataforma. LinkedIn mantiene identidad y estrategia editorial propias. No se deduce la relación de títulos, fechas o cifras. No se modifica el comportamiento de informes existentes en este incremento.

Quedan excluidos OAuth ejecutable, almacenamiento real de secretos, transporte HTTP real, tareas programadas, generación semanal, correo, publicación y mensajería. Cualquier evolución posterior exige una solicitud nueva; este trabajo no inicia I4-A2.
